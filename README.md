# PortPilot

PortPilot 是一个 macOS 本地开发端口面板，用于查看当前监听的 TCP/UDP 端口，并通过自定义命令在 Terminal 中一键启动开发服务。

维护人：libo

## 当前功能

- 右上角悬浮窗口和菜单栏常驻
- 登录后自动启动
- 每 3 秒读取本机端口快照，但只展示已配置端口和疑似开发进程端口
- 自动识别 Node、Python、Vite、Next、ADB、Docker 等常见开发进程
- 显示端口、协议、类别、地址、进程和 PID
- 为端口保存自定义名称、启动命令和工作目录
- 在新的 Terminal 窗口中启动服务
- 支持确认后终止端口对应进程、置顶端口和拖动排序
- 使用 `⌥⌘P` 全局隐藏/展示窗口
- 启动指令保存在本机用户配置中

## 构建运行

```bash
./Scripts/build-app.sh
open .build/PortPilot.app
```

首次通过启动指令打开 Terminal 时，macOS 可能会请求自动化权限。

## 说明

端口扫描使用系统自带的 `/usr/sbin/lsof`，不需要额外安装 Node、Python 或其他运行时。为发现 AI 临时启动的未知端口，PortPilot 会读取本机端口快照，但不会占用或监听任何端口；界面只展示已配置端口和常见开发进程产生的端口。自动发现的端口可以直接点击编辑按钮命名，保存为仅监控端口；也可以补充启动命令，之后从面板一键启动。端口行支持星标置顶、拖动排序和停止操作；普通进程发送终止信号，Docker 端口会停止对应容器，并在执行前确认。对于进程名特殊的服务，可在“启动指令”中手动配置端口。
