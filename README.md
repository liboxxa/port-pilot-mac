# PortPilot

PortPilot 是一个 macOS 本地开发端口面板，用于查看当前监听的 TCP/UDP 端口，并通过自定义命令在 Terminal 中一键启动开发服务。

## 当前功能

- 右上角悬浮窗口和菜单栏常驻
- 登录后自动启动
- 每 3 秒读取本机端口快照，但只展示已配置端口和疑似开发进程端口
- 自动识别 Node、Python、Vite、Next、ADB、Docker 等常见开发进程
- 合并 `--reload` 父子进程共享的同一监听 socket，并识别 Prometheus 监控端口
- 显示端口、协议、类别、地址、进程和 PID
- 监听端口支持通过“更多”菜单编辑、设置颜色和隐藏；隐藏端口会在底部折叠显示
- 端口和启动指令编辑直接在主窗口内完成，不弹出独立编辑窗口
- 为端口保存自定义名称、启动命令和工作目录
- 在后台启动和停止服务，不弹出 Terminal 窗口
- 捕获由 PortPilot 启动的命令输出和错误日志，命令异常退出时弹窗提示
- 点击端口行或启动指令行可在主窗口内打开运行日志，支持开始/暂停、输入指令、滚动和复制；日志顶部的预设命令可直接点击编辑
- 支持确认后终止端口对应进程、置顶端口和拖动排序
- 可按住窗口顶部或底部边界空白区移动窗口，端口条内部拖动仍用于排序
- 置顶的启动指令端口即使停止后仍保留在列表顶部，并显示绿色启动按钮
- 启动指令的端口可留空，启动后会自动识别新出现的开发端口并回填
- 使用 `⌥⌘P` 全局隐藏/展示窗口
- 启动指令保存在本机用户配置中

## 构建运行

```bash
./Scripts/build-app.sh
open .build/PortPilot.app
```

首次通过启动指令打开 Terminal 时，macOS 可能会请求自动化权限。

## 说明

端口扫描使用系统自带的 `/usr/sbin/lsof`，不需要额外安装 Node、Python 或其他运行时。为发现 AI 临时启动的未知端口，PortPilot 会读取本机端口快照，但不会占用或监听任何端口；界面只展示已配置端口和常见开发进程产生的端口。自动发现的端口可以直接点击编辑按钮命名，保存为仅监控端口；也可以补充启动命令，之后从面板后台启动。启动指令的端口可以留空，PortPilot 会记录启动前的端口快照，启动命令执行后自动识别新出现的开发端口；如果一次启动多个新端口，会要求手动填写以避免错误绑定。所有正在运行的开发端口都会显示灰色暂停按钮，未运行的启动指令显示绿色启动按钮；未绑定启动命令的自动发现端口暂停前会要求确认。启动和停止都不会弹出 Terminal 窗口。端口行支持星标置顶和拖动排序；对于进程名特殊的服务，可在“启动指令”中手动配置端口。

运行日志只对由 PortPilot 启动的命令有效，PortPilot 会从命令启动时开始捕获 stdout/stderr，并可向仍在运行的命令发送输入；AI 或其他程序从外部启动的进程无法补读启动前已经输出的历史命令行内容，也无法接管 stdin，点击这类端口时会显示端口、进程和 PID 信息说明。

## 使用文档

### 一、安装与启动

PortPilot 当前通过源码构建：

```bash
cd /Users/libo/Desktop/daun
./Scripts/build-app.sh
open .build/PortPilot.app
```

构建完成后，应用位于 `.build/PortPilot.app`。PortPilot 会常驻菜单栏，并默认显示悬浮窗口。

首次使用启动指令时，macOS 可能会请求自动化或相关权限，按系统提示允许即可。

### 二、窗口操作

窗口左上角的三个系统原生按钮分别用于：

- 红色：关闭窗口。应用仍会保留在菜单栏中。
- 黄色：最小化窗口。
- 绿色：缩放窗口。

其他操作：

- 右上角刷新按钮：立即重新扫描端口。
- `⌥⌘P`：全局隐藏或显示 PortPilot 窗口。
- 菜单栏 PortPilot 菜单：隐藏/显示窗口或退出应用。
- 顶部和底部的空白区域：拖动窗口。

窗口会每 3 秒自动刷新一次端口状态。

### 三、监听端口

点击“监听端口”进入端口列表。每条端口记录通常包含端口号、协议、名称、进程、PID、置顶、暂停/启动、运行日志和“更多”菜单。

#### 查看日志

点击端口行主体，会在当前 PortPilot 窗口内切换到日志详情页，不会打开独立弹窗。

日志详情页支持：

- 返回端口列表。
- 开始或暂停对应启动指令。
- 点击顶部预设命令进入编辑页面。
- 查看、滚动和复制日志。
- 向由 PortPilot 启动且仍在运行的命令发送输入。

#### 更多菜单

点击端口右侧的三个点，可以使用：

- 编辑：修改端口名称、端口和启动指令。
- 颜色：设置默认、蓝色、紫色、绿色、橙色、红色或黄色。
- 隐藏：将端口移动到列表底部的隐藏区域。

颜色设置按协议和端口号保存，会显示为整行浅色背景、边框和名称颜色。

隐藏端口不会被删除，会在列表底部合并到“隐藏端口”区域并默认折叠；点击“展开”即可查看。隐藏端口的更多菜单中可以选择“显示”恢复到普通列表。

#### 置顶、排序和停止

- 点击星标可以置顶或取消置顶。
- 拖动端口行左侧的拖动区域可以调整顺序。
- 对正在运行的端口点击暂停，会尝试停止对应进程。
- 未绑定启动指令的自动发现端口，停止前会要求确认。
- 端口行右键菜单可以终止占用该端口的进程。

停止进程可能同时释放该进程占用的其他端口。Docker 端口会尝试停止对应容器。

### 四、启动指令

点击“启动指令”进入自定义命令列表，点击“添加”后填写：

| 字段 | 说明 |
| --- | --- |
| 名称 | 列表中显示的服务名称，必填。 |
| 端口 | 要绑定的端口，可留空。 |
| 命令 | 要执行的 shell 命令，例如 `npm run dev`，可使用多行命令。 |
| 工作目录 | 命令执行目录，可选。 |

端口留空时，PortPilot 会记录启动前的端口快照，并尝试识别启动后新增的开发端口：

- 发现一个新开发端口：自动绑定该端口。
- 发现多个新开发端口：提示无法安全判断，需要手动填写端口。
- 未发现端口：命令仍可继续运行，但不会自动绑定端口。

编辑页面直接显示在主窗口内，不会弹出独立窗口。保存或取消后返回原来的列表或详情页。

每条启动指令右侧的三个点菜单包含：

- 编辑：修改名称、端口、命令和工作目录。
- 删除：删除本机保存的启动指令。

点击列表中的启动指令主体可以打开运行日志。右侧绿色播放按钮用于开始，暂停按钮用于停止。

### 五、运行日志与命令输入

PortPilot 只会捕获由自己启动的命令输出：

- stdout 和 stderr 会持续写入日志。
- 命令异常退出时会标记失败并提示退出状态码。
- 日志最多保留最近约 60,000 个字符。
- 日志详情页的输入框支持输入内容并按回车或点击“发送”。

命令输入会写入 PortPilot 启动进程的 stdin，适用于支持交互输入的开发服务。

以下情况不能发送输入：

- 进程由 Terminal、AI 工具或其他程序从外部启动。
- 命令尚未通过 PortPilot 启动。
- 进程已经退出。

外部进程仍可以查看端口、进程和 PID，但无法补读 PortPilot 启动前已经产生的历史输出，也无法接管 stdin。

### 六、常见问题

#### 端口没有出现在列表中

PortPilot 默认展示已配置端口，以及被识别为开发进程的端口。可以在“启动指令”中添加该端口，或通过端口列表的编辑入口配置名称和命令。

#### 启动命令失败

先检查工作目录、命令和运行时环境。PortPilot 会显示失败提示；进入对应端口或启动指令的日志详情页可以查看 stdout/stderr 和退出状态码。

#### 日志输入框不能发送

只有由 PortPilot 启动且仍在运行的命令才有可用 stdin。外部进程和已经停止的进程无法接收输入。

#### 端口暂停后仍然存在

部分进程可能忽略 SIGTERM，或者子进程仍在占用端口。稍等片刻后刷新；如果仍未释放，可以使用端口右键菜单终止进程，或手动处理对应服务。

#### 端口被隐藏后找不到

滚动到端口列表底部，点击“隐藏端口（数量）”展开。隐藏只是列表展示状态，不会停止进程或删除配置。

### 七、数据与权限说明

- 启动指令、端口顺序、置顶状态、隐藏状态和颜色保存在本机用户配置中。
- 端口扫描使用系统自带的 `/usr/sbin/lsof`，不会监听或占用端口。
- 启动和停止服务默认在后台执行，不主动打开 Terminal 窗口。
- PortPilot 不会补读外部程序已经产生的历史命令行输出。
